# Gerentes de restaurante

Conteúdos da PromptLab.AI voltados a gerentes, supervisores e líderes de operação de restaurantes.

## Objetivo

Criar prompts práticos para organizar turnos, equipe, reservas, estoque, ocorrências, atendimento e continuidade operacional, sempre preservando a decisão humana e os procedimentos internos do estabelecimento.
